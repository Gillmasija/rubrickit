# Delivery milestones

Verify and commit each step before beginning the next. No rewritten history.

1. Working static setup and matching favicon (`Setup done`); build and syntax checks.
2. Project brief and acceptance criteria; open draft PR before app implementation.
3. Bounded rubric model and weighted calculation; unit tests.
4. Versioned local storage and conflict protection; persistence tests.
5. Three-page navigation and visual system; build and link checks.
6. Rubric and criterion editor; validation and model checks.
7. Scoring workspace and sample journey; weighted calculation tests.
8. Printable feedback report; incomplete and complete result checks.
9. JSON backup, restore and recovery; invalid-input tests.
10. Responsive and accessible interaction refinements; browser verification.
11. Automated browser acceptance tests; production-build journeys.
12. CI, documentation, screenshots and final acceptance evidence; all checks.

Add focused fixes when verification reveals defects. Mark the same PR ready only
after the acceptance criteria and final checks pass.
